# Tetris in C

A simple terminal-based Tetris game written in C for Linux.

### Controls
- `A` / `D` — Move left / right
- `S` — Move down
- `Z` — Rotate piece

### Build
```bash
gcc main.c -o tetris
./tetris
```

### Inspiration
Heavily inspired by [OneLoneCoder's Command Line Tetris](https://github.com/OneLoneCoder/Javidx9/blob/master/SimplyCode/OneLoneCoder_Tetris.cpp), originally written in C++.
